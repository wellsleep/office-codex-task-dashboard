只读读取本机 Codex 任务配置、运行索引及明确关联的会话完成回执。普通定时任务按一次运行会话记账，后续重试反映在该记录的最新结果；原对话定时任务按触发轮次分别记账。耗时包含会话内等待与重试。

“原文明确”表示最终回复明确陈述结果；“规则推断”表示根据回复内容推断。两者均不是对外部系统的再次验收。已读、已归档不作为成功依据。时间范围按启动时间筛选。

任务时间表按当前配置展示，不追溯历史配置。“疑似逾期”仅在调度器下次运行时间已过两小时后提示，不能据此认定漏跑。电脑休眠期间无法采集。

公开页面仅保留精简摘要。完整日志仍在本机；“在 Codex 查看”链接需要安装 Codex 且能访问原任务，手机通常无法打开。
